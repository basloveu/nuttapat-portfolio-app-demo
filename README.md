## 🏁 Getting Started <a name = "getting_started"></a>

Download Project ลงบนคอมพิวเตอร์ของท่าน

### Prerequisites

คอมพิวเตอร์ของท่าน ต้องมี NodeJS

```
node -v
```

### Installing

เปิด Terminal เข้าไปที่โฟลเดอร์ที่ติดตั้ง Project

ติดตั้ง Node Modules

```
npm install
```

ติดตั้ง Package ที่ต้องใช้งาน

```
npm install @popperjs/core @tailwindcss/vite bootstrap bootstrap-icons pinia devicon
```
## 🔧 Running<a name = "tests"></a>

## 🚀 Deployment <a name = "deployment"></a>

รันคำสั่งแล้ว Code Build จะไปอยู่ในโฟลเดอร์ Dist สามารถนำไฟล์ในโฟลเดอร์ไปวางเพื่อใช้งานบน Server ที่ต้องการได้เลย
```
npm run build
```
